# Brand Axis Website

GitHub + Netlify ready static website.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services overview
- `brand-analysis.html` — Brand Analysis sales page
- `content-direction.html` — Content Direction sales page
- `creative-production.html` — Creative Production sales page
- `work.html` — Selected Work & Concepts
- `contact.html` — Contact / inquiry form

## Netlify
- Branch: `main`
- Build command: leave blank
- Publish directory: `.`

The inquiry form uses Netlify Forms.

## Updating GitHub
Upload the contents of this folder to the repository root so `index.html` remains at the top level.
