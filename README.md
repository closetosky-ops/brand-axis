# Brand Axis Website

GitHub-ready multi-page static website based on the approved Brand Axis mockup.

## Pages
- `index.html` — Home
- `services.html` — Services
- `work.html` — Selected Work & Concepts
- `about.html` — About
- `contact.html` — Contact / Netlify form

## Deploy with GitHub + Netlify
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In Netlify, choose **Add new site → Import an existing project → GitHub**.
4. Select the repository. No build command or publish-directory change is needed; publish the repository root.
5. Connect your custom domain.

## Before launch
- Replace the calendar link on `contact.html` when your booking URL is ready.
- Confirm email and phone.
- Netlify will capture the contact form automatically after the first deploy.

The `/reference` folder contains the generated mockups used to reproduce the approved look.
