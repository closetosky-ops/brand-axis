# Brand Axis

Static Brand Axis website for GitHub + Netlify.

## Separate service pages
- `/brand-analysis/`
- `/content-direction/`
- `/creative-production/`

The Services dropdown links directly to those pages. The Services overview remains at `/services`.

## Deploy
Upload the **contents** of this folder to the root of the GitHub repository and commit. Netlify will redeploy from `main` automatically.
